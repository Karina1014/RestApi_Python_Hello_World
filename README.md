# 🌍✨ RestAPI Hello World App
### 📜 About the Project
This is a simple Flask application that demonstrates how to create a REST API in Python. The app responds to a GET request at the root endpoint (/) with a cheerful "Hello, World!" message.

## 🚀 Getting Started
**🛠️ Prerequisites**
* 🔍 Ensure Python is installed on your system.*
Check the version by running:
```bash
python --version
```
⚡ Required version: 3.8.3 or later.

## 📥 Installation

**1️⃣ Clone the repository:**
```sh
   git clone https://github.com/Karina1014/Grpc_golang_Hello_World.git
  ```
**2️⃣ Set up a virtual environment**:
```sh
python -m venv venv  
venv\Scripts\activate   
```
**3️⃣ Install the required packages**:
```sh
pip install flask  
```

## ⚙️ Running the App
▶️ Start the Flask server:
```sh
python main.py
```
🌐 Open your browser and navigate to:
http://127.0.0.1:9000
✨ You’ll see the message: Hello, World!
